Design Philosophy

Radical Simplicity

  • ✓
    Leverage existing tools
    Claude Code, Mastra, Tailscale—not custom infrastructure
  • ✓
    Git-native persistence
    Branches store everything, PRs for promotion
  • ✓
    Port-based routing
    Each service at root path—no rewriting complexity
  • ✓
    SQLite default
    Zero config to start, PostgreSQL when needed

Security & Access Control

🔐 Tailscale Mesh

End-to-end encryption, no public exposure. ACL-based access control per session.

🔑 Project Secrets

K8s secrets per environment. API keys, DB credentials injected at runtime.

Invite teammates to live sessions. Pair debugging with full context.
